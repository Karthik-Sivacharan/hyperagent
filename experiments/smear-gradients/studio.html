The family

Ten generated ramps either side of the two measured ones. They hold the same OKLCH recipe — one lightness range, one chroma envelope, 40–100° of hue travel — and the same field settings, so hue is the only thing really changing. Click any one to load it above.

What the reference frames measure

Both images were analysed the same way: a windowed FFT for the streak axis, banded autocorrelation for the blur length, and principal components in sRGB to test whether the colour really is one ramp. It is.

A caution worth repeating: an FFT angle taken from bin indices is wrong on a non-square image. On these 1024×768 frames that error reads +7°. Convert bins to cycles-per-pixel (fx=Δx/W, fy=Δy/H) before taking the angle, or calibrate against synthetic noise blurred at a known angle — which is how the +7° was caught.

The five pieces

Anisotropic fBm
Value noise sampled on a domain rotated to θ and 5–8× coarser along the streak axis than across it. Stretch alone gives soft blobs.
Directional blur
A box average along θ, 15–20% of the frame's long edge. Blur alone gives a flat smear; stretch and blur together give streaks.
Linear bias
A plain ramp across the streak axis, mixed in. The blue frame leans on it (34%); the orange barely uses it (3%).
The ramp
One curve through OKLab, sampled continuously. Interpolating in sRGB instead puts a grey sag through the middle of any hue-crossing ramp.
Smeared grain
White noise box-averaged along the same θ, added in linear light at ~1/255, then triangular dither. This is what separates the look from vector art.

Three ways to ship it

Same formula, three budgets.

Runtime · GPU

Fragment shader

What this page runs. The blur is N taps along θ, which costs octaves × taps noise evaluations per pixel. Render on parameter change, not in an animation loop, and it is free at rest.

Build time · CPU

Node → PNG

Shear, box-blur, unshear gets an exact line integral in one pass per row. The shear must move columns vertically — a row shear cancels itself and silently leaves you a horizontal blur.

Zero JS · CSS

SVG filter

feTurbulence with an anisotropic baseFrequency, a one-axis feGaussianBlur, and feComponentTransfer as the gradient map. Coarser, but it is a background-image with no script at all.
