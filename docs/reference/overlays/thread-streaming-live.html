Example found: Microsoft Design's "Designing the first five minutes" — research on users meeting a sales agent for the first time.
  • Output before setup. Produce something useful from near-zero input, then ask for context once the user can see why it improves the result. Setup-first onboarding feels slow no matter how short it is.
  • Small steps, immediate payoff each. Never block on complete inputs — partial config should still yield partial output, so every answer visibly buys something.
  • Narrate the wait. Plain-language progress ("reading your tickets," "drafting outreach") plus rough time expectations stop users re-prompting; silence reads as lag even when it's fast.
Bonus: infer personalization from connected data rather than asking (Macha's welcome chat opens by citing your real open tickets) — it's personalization with zero questions.
